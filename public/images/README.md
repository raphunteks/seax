# Asset slots

Drop real photos here. Nothing is required to run the site: until a file exists, product art is drawn in SVG.

| File | Used by | Size | Notes |
|---|---|---|---|
| `menu/<slug>.webp` | Favorites cards | 800x1000, transparent or ink background | slugs: kopi-aktif-aren, kopi-aktif-aren-premium, kopi-sosial-ice, kopi-sosial-hot, americano-ice, peach-mont-blanc, matcha-cloud, lemon-honey |
| `order-table.webp` | Order ahead section | 1920x1280 | dark table with plates, optional |
| `og.jpg` | Open Graph | 1200x630 | |

Logo: place the official SVG at `public/brand/logo.svg`. The site currently sets the word "sea" in Unbounded as a stand-in.
